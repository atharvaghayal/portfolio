# Atharva Ghayal - Blogs Directory

A lightweight React-based portfolio component designed to host professional publications, technology reviews, and study guides. Part of the multi-site developer portfolio layout.

## Features

- **Micro-nav Links:** Top navigation bar enabling routing between the main portfolio landing page (port 3000) and the projects showcase (port 3001).
- **Elastic Viewport Pull:** Custom elastic edge scroll feedback when reaching limits of the layout view.
- **Responsive Card Layout:** Adaptive central card displaying active page build indicators.

## Run Locally

### 1. Installation

Run installation in the project folder:

```bash
cd blogs-site
npm install
```

### 2. Run Development Server

```bash
npm start
```

Runs on [http://localhost:3002](http://localhost:3002).
