# Atharva Ghayal - Developer Portfolio

An interactive, responsive developer portfolio showcasing technical experience, tools, and background. Built using React, GSAP, and Framer Motion, it features custom animations and modular layouts.

## Core Features

- **Interactive Terminal Hero:** A simulated terminal command prompt with live-typing animation, displaying personal details, skills, and background.
- **Toggleable Work & Education Timeline:** A dynamic section showing professional experiences and academic history with smooth slide transitions.
- **Infinite Logo Loop:** A responsive, hardware-accelerated carousel looping technical skills, languages, and tools.
- **Elastic Scroll Boundaries:** A custom boundary feedback animation triggering gentle offset transitions at viewport edges.
- **Spark Click Particles:** High-performance spark animations trailing cursor click interactions.
- **Views Counter:** A session-based localStorage counter animated with GSAP `power3` easing.

## Tech Stack

- **Framework:** React 19
- **Animation:** GSAP 3, Framer Motion
- **Icons:** React Icons
- **Styles:** Custom responsive CSS using modern fluid typography and variables

## Getting Started

### 1. Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (LTS recommended).

### 2. Installation

Clone the repository and install the dependencies:

```bash
cd my-site
npm install
```

### 3. Run Development Server

Start the local server to preview the site:

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### 4. Build for Production

Compile optimized production assets:

```bash
npm run build
```
