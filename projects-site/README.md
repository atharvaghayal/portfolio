# Atharva Ghayal - Projects Portfolio

A React application displaying various software development projects, case studies, academic work, and active research. Part of the multi-site developer portfolio layout.

## Features

- **Categorized Project Hub:** Separates work logically into active R&D labs, deep dive Case Studies, and College Group projects.
- **Chroma Grid Card Layout:** A fluid grid displaying custom-styled cards with gradient backgrounds, border highlights, and interactive preview overlays.
- **External Redirection:** Standardized navigation triggers directing visitors to external GitHub code repositories or live hosts.
- **Micro-nav Links:** Top navigation bar enabling direct routing between the home page (port 3000) and blogs directory (port 3002).
- **Interactive Cursor Sparks:** Line-shaped mouse spark trailing click feedback.
- **Elastic Scroll Physics:** Elastic boundaries offset animation when pulling past document viewport edges.

## Run Locally

### 1. Installation

Run installation in the project folder:

```bash
cd projects-site
npm install
```

### 2. Run Development Server

```bash
npm start
```

Runs on [http://localhost:3001](http://localhost:3001).
